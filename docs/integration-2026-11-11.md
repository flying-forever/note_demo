## 职责与状态

页面 → viewmodel/NoteEditorSession、services/NoteService → repository → model；platform 处理卡片通知、媒体文件、分享与启动解析。存储不依赖卡片配色和刷新 API。

- 编辑会话持有唯一标题、正文块、图片、历史、活动位置和脏状态；页面通过 @State/@Observed 订阅，不复制草稿。
- 业务入口统一主编辑与半模态保存、空白判断、ID/时间构造、附件引用和快照冲突检查。
- Repository 保留内存与选择性 JSON、关联与墓碑；平台/UI 持有焦点、键盘、滚动、弹层和动画运行时。
- 保存失败不提前更新内存；已落盘但卡片刷新失败不回滚或误报存储失败。快照比较不是跨进程原子并发控制，数据库事务仍属后续阶段。

## UI 风格审查与暂挂项

本轮核对了首页卡片、导航、皮肤选择、更多、移动、图片操作、描述和详情：导航主要按钮44vp，正文17sp，标题26sp，页面边距16vp；弹层使用统一圆角和当前皮肤颜色。修正深色皮肤“移动到”标题颜色、满宽描述面板和顶部遮挡的皮肤选择器。

- “点击长正文某个字后，光标准确落在该字”暂挂。本轮修复视口恢复并接入块光标控制，但浏览 Text 到 TextArea 的精确点击位置映射仍需专门设计；不提前迁移原生 RichEditor 或长文按需渲染。
- 系统“完成”自动保存未实现，采用用户允许的明确保存提示方案；系统宿主未提供可靠公开回调，取消不应触发隐式保存。
- 本轮物理中文预输入、不同输入法、折叠/展开两种屏幕切换、桌面真实冷启动及半模态完整人工流程、长时动画资源压力仍需补充验收；模型/会话回归不替代这些实机场景。
- 核心结构迁移完成，R0～R4 全部阶段出口是否通过仍以完整验收为准，不声称每个设备场景已覆盖。
