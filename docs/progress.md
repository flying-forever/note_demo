# 项目进度

更新日期：2026-11-13。本文件是当前状态及待办的唯一汇总；旧过程见[历史快照](archive/2026-11-12-progress.md)。规格、架构、实验数据各在对应文档维护，不在此重复流水账。

## 当前能力与阶段

- 首页支持双列列表、分组/未分类、皮肤配色、圆角视口、大小导航与搜索栏手势；实际搜索、文件夹管理、设置及待办仍未接通。
- 主编辑支持图文、撤销重做、纯文本分享、移动与12款皮肤。浏览/编辑切换保持滚动视口，标题与正文已接入真实排版的首击光标定位。现行规则见[页面规格](pages.md)。
- 桌面卡片支持添加、关联、刷新、打开目标、删除占位与半模态文字编辑。应用按钮为“保存并结束编辑”；取消不保存。SDK19无法接管宿主完成或关闭其预览弹窗，该限制是当前确认方案，不是未实现的自动保存需求。
- 笔记数据源已切到 `notes.db`（relationalStore，schema v3）：正文块表权威、单块保存，首页只读摘要、编辑页按 ID 读整篇；自动草稿表、编辑停顿写入与强杀恢复已接；桌面卡片读旧 JSON 投影，半模态优先读库并回退投影。缩略图已生成并优先用于正文，原图压缩与10万字按需渲染未接，文字笔记已有长文外壳入口。契约见[数据模型](data-model.md)。
- 动态皮肤已合入，核心结构迁移已实施；阶段计划不再作为待执行重构任务。未完成的质量门槛保留在下表，不能宣称R0～R4所有场景全部验收通过。
- 持久化阶段2基础看板已闭环：表结构、事务化 Repository、JSON 迁移、CRUD、revision 条件更新、首页摘要读取、编辑页按 ID 懒加载与半模态读库在真机验证；迁移逐 ID 校验留待后续。最新结论见[技术实验现状](technical-demos.md)，实施顺序见[持久化计划](plans/persistence-plan.md)。
- 阶段3基础闭环：schema v3 `drafts` 表、约 800ms 编辑停顿写入、离页/销毁冲刷、首页草稿条、恢复提示与旧版本 `base_revision` 校验、空白草稿清理；附件导入改为 `.part` 先落盘、500KB 上限、失败删除，缩略图长边 960/质量 75 导入生成并启动补建，删除笔记同时删附件记录并立即清理该笔记原图/缩略图，启动清理无引用且超过 60 秒的原图与孤立缩略图。真机验证强杀后恢复、恢复/忽略、空白草稿强杀不残留、图文草稿恢复、旧版本提示、删除带附件笔记后立即清理，自检通过 schema v3、草稿表读写删、缩略图生成、超大文件拒绝与 `.part` 清理、孤立原图/缩略图删除、删除笔记附件清理；跨进程导入竞态未专项，原图压缩未做，导入压缩/降级待修（见插图回归）。
- 已知回归：500KB 硬上限对普通相册照片生效，插图失败只提示“无法插入图片，请重新选择”；设备现有旧附件约 2.89MB。待做导入压缩与具体原因提示。
- 阶段4按 4a/4b 推进：4a 文字基础已接最小外壳 `NoteEditorWeb`，主编辑「更多 → 长文编辑」进入，按 ID 读文字笔记，标题原生输入、正文 CodeMirror，返回整篇保存；真机通过中文、退格删除、返回保存、正文无引号、块 ID 保留、两行正文定位到第二块和强杀草稿恢复。已定并实现 800ms 草稿定时写入、实时字数按块缓存+总数差值+保存全量校验、块级定位以只读态滚动到块。4a 仍缺拆块/合块/旧块内含换行的稳定处理、撤销分组和真实粘贴验证。4b 已能在 Web 打开旧含图笔记并显示缩略图/图注；新图插入、图文保存、图片浮层、精确偏移与单段 10 万字未做。图片仍属阶段 4，不搁置，单段 10 万字暂缓但保留验收。
