# 项目进度

更新日期：2026-11-13。本文件是当前状态及待办的唯一汇总；旧过程见[历史快照](archive/2026-11-12-progress.md)。规格、架构、实验数据各在对应文档维护，不在此重复流水账。

## 当前能力与阶段

- 首页支持瀑布/列表两种视图、设置菜单、分组/未分类、皮肤配色、圆角视口、大小导航与搜索栏手势；实际搜索、文件夹管理及待办仍未接通。独立设置页仅有标题与返回，具体设置项待定。
- 主编辑支持图文、撤销重做、纯文本分享、移动与12款皮肤。浏览/编辑切换保持滚动视口，标题与正文已接入真实排版的首击光标定位。现行规则见[页面规格](pages.md)。
- 桌面卡片支持添加、关联、刷新、打开目标、删除占位与半模态文字编辑。应用按钮为“保存并结束编辑”；取消不保存。SDK19无法接管宿主完成或关闭其预览弹窗，该限制是当前确认方案，不是未实现的自动保存需求。
- 当前仍为进程内笔记与选择性JSON持久化：发送桌面的笔记启用保存；尚未接入全部笔记数据库、自动草稿和正式10万字按需渲染。契约见[数据模型](data-model.md)。
- 动态皮肤已合入，核心结构迁移已实施；阶段计划不再作为待执行重构任务。未完成的质量门槛保留在下表，不能宣称R0～R4所有场景全部验收通过。
- 持久化处于阶段1技术验证，尚未通过整体出口。最新结论及原因见[技术实验现状](technical-demos.md)，实施顺序见[持久化计划](plans/persistence-plan.md)。
- 隐私编辑首轮按行 Demo 已提交为 `3c9e379`（不含用户个人备忘）；后续为目标宽192vp、视觉行高30vp的局部矩形，保留浅灰无字形短条和按行对照，仅内存样例。用户反馈连续输入闪定位提示和正文，本轮调整为普通输入保留上次有效窗口、合并排版刷新，相同尺寸/滚动偏移不重复失效；真实滚动或尺寸变化仍全遮，左右裁字风险保留。变更纳入本轮提交；构建/真实函数回归通过，英文连续键入离散画面未见全遮空帧或定位提示，实际软键盘逐键拼音选词与Home返回全遮已有局部验证，不代表高速连续中文或逐帧无闪烁。候选设计见[开发计划](plans/privacy-editor-demo-plan.md)，结果见[本轮记录](archive/2026-11-13-privacy-editor-input-refresh.md)。
- 主窗口已接入系统栏沉浸：全屏、透明状态栏/导航栏、上下避让和按页面/皮肤切换图标；DMG-W00 已验收透明呈现、深浅皮肤图标、浮动键盘和横竖屏，三键导航/折叠/其他设备待验，看板见[系统栏适配](plans/system-bars-plan.md)。
