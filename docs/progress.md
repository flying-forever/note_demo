## 踩坑记录

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| DevEco 内置 Git 看不到 `note_by_agent/` 内文件修改，只看到顶层文件 | `.idea/vcs.xml` 残留 `$PROJECT_DIR$`（= `note_by_agent`）映射，但该目录已无 `.git`，形成无效 Git 根并接管了子文件 | 删除该映射，仅保留 `$PROJECT_DIR$/..`（= `note_demo`）；或把 `note_demo` 作为项目根打开；改完 Invalidate Caches / Restart |
| 到顶下拉展开搜索后松手回弹，搜索栏又消失、变回大标题 | `edgeEffect(Spring)` 回弹产生正向 `deltaY`，被 `deltaY > 0` 判为上滑而调用 `hideSearch` | 收起判定改用真实内容偏移：仅 `offset > 8`（内容真的滚离顶部）才收起；回弹时 `offset ≤ 0` 直接忽略 |
| 顶部小幅下拉出现「标题 → 半显搜索栏 → 标题」闪烁 | `searchProgress` 跟手连续变化，与同槽大标题的半透明态叠加；未过阈值松手回弹复位 | 改阈值触发 + 整段动画：下拉阶段不进入半显态，过阈值才 `animateTo` 展开；`SearchBar` 常驻挂载、只控 `opacity`，避免 0 附近反复挂载/卸载 |
