# 项目进度

## 当前状态

M1 首页原型已在设备上验证，可进入编辑页阶段。首页使用 20 条假数据，支持双列浏览、分组筛选、大小导航切换和搜索栏手势。搜索栏尚未接入查询。设置、文件夹、新建和编辑入口仍是提示占位，待办页也只有占位内容。命令行构建、安装和启动流程已验证。

## 下一阶段：纯文本编辑闭环

1. 开工前确认保存方式（返回时自动保存，或点「完成」保存），并更新 [页面规格](pages.md)。
2. 点击首页卡片进入编辑页并载入笔记，点击「＋」进入空白编辑页。先使用内存数据。
3. 验收时在设备上各走一遍新建和编辑流程，保存返回后首页立即显示结果。

后续再接入本地持久化、实际搜索、文件夹管理和待办。存储方案见 [数据模型](data-model.md)。

## 待修复：首页分组滑动

- 复现：在首页切换到「旅途」等非「全部」分组，上滑笔记列表并松手。大导航栏会随列表回弹重新展开，无法保持收起。
- 排查方向：确认短列表的可滚动距离是否小于导航栏收起所需的 56vp，以及松手回弹后内容偏移是否归零。原因待验证。
- 验收：短分组上滑达到收起条件时，松手后保留顶部小导航。下拉可恢复大导航，搜索栏仍按现有规则展开。「全部」分组滑动正常。
- 安排：首页交互集中修复时处理。
