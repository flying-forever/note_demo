# 隐私编辑 Demo 开发计划

创建日期：2026-11-13。本文是首轮实验的候选设计与开发计划，不是正式笔记编辑器规格；实施状态与未验收项统一见[项目进度](../progress.md)，实验现状见[技术实验现状](../technical-demos.md)。

## 目标与边界

验证公共场合写日记时，只显示光标附近少量文字是否既能减少屏幕内容暴露，又不妨碍持续输入、改字与短暂回看。用户已授权本轮自行决定首版细节并完成 Demo，先看效果再决定正式产品方案。

入口为首页设置长按 → 技术实验室 → 隐私编辑。页面为 `pages/PrivacyEditorDemo.ets`，在 `diagnostics/DemoCatalog.ets` 和 `main_pages.json` 注册，沿用 `TECH_DEMOS_ENABLED` 开关。

首版仅使用内存中的纯文字样例与用户在实验页的临时输入，不读取正式笔记、不落盘，离开实验页不保存。无图片、标题独立编辑、分享、笔记锁定、加密、首页摘要遮挡或桌面卡片保护；不承诺输入法候选词、系统截图、后台任务缩略图、无障碍输出已获得保护。

## 设计依据

- [ZenJournal Discreet Mode](https://thezenjournal.com/posts/discreet)：隐藏历史日记而保留输入入口，说明公共场合继续写作与遮挡旧内容可以共存；其时间线方案不直接等同于长文光标附近遮挡。
- [iA Writer Focus Mode](https://ia.net/writer/support/editor/focus-mode?tab=focus-mode-mac)：跟随光标突出当前句或段，可借鉴活动区域选择；其余文字变灰仍可阅读，首版不将其当作隐私遮挡。
- [TextArea 共用控制器接口](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-universal-attributes-text-style/)：`getCaretOffset` 提供原生光标位置；同帧更新存在读取时序限制，必须验证排版与遮罩同步，不能以接口存在推断效果通过。

## 首版交互

| 场景 | 候选行为 |
| --- | --- |
| 进入实验页 | 默认启用隐私遮挡，尚未取得有效光标与排版信息时保持全遮 |
| 正常输入 | 只显示当前视觉行；视觉行指屏幕自动折行后的行，不是按回车划分的整段 |
| 更多上下文 | 可切换为当前视觉行与上一行，便于比较隐私范围和写作连贯性 |
| 移动光标、换行或滚动 | 根据原生光标坐标更新可见带，其余区域用不透明遮罩覆盖；位置失效时全遮，不猜测字符宽度 |
| 临时回看 | 按住查看全文，松手、触摸取消或手指滑出按钮即恢复遮挡，不提供无提示的持续全文显示 |
| 主动暂停 | 一键全遮；用户主动恢复后再取得有效位置，回到局部显示 |
| 收起键盘或结束编辑 | 保持隐私模式并全遮，不能因转为非编辑状态显示全文 |
| 页面隐藏、窗口失焦或应用退后台 | 取消全文查看并全遮；回到页面后需要主动恢复，过期回调不能重新打开可见带 |
| 跨行选择 | 不能因选区变大而扩大可见带；原生选择菜单、放大镜和系统复制的实际表现单独验收 |

遮罩保持原有正文排版空间。首版不强制打字机居中，不以模糊或低透明度文字作为隐藏手段，不增加随每次输入而播放的动画。

## 实施步骤与职责

1. 核对当前正式规格和 API19 本地声明，固定隔离数据与实验路由。正式编辑器的保存、历史和数据库路径均不接入本实验。
2. 在独立页使用一个固定视口 `TextArea` 保存完整原文草稿；沿用原生中文预输入与光标能力，不把原文替换成星号，不截取另建可编辑草稿。
3. 建立独立的隐私显示状态，包含局部显示、按住全文查看、全遮，以及页面/窗口活动状态。通过原生光标坐标驱动上、下两块不透明遮罩；字号、行高、间距集中定义，颜色引用现有资源。
4. 接入内容、光标、滚动和布局变化后的坐标刷新，处理像素/vp转换与当前视口裁切。刷新期间或坐标无效时先全遮；异步结果带生命周期检查，页面离开时注销监听并使待处理回调失效。
5. 加入一行/两行切换、按住查看全文、全遮/恢复和样例体验入口，保证触摸取消与滑出恢复遮挡。
6. 命令行构建，随后按下表做可安排到的真机验证；根据实际结果更新[技术实验现状](../technical-demos.md)和[项目进度](../progress.md)。首轮反馈前不将候选规则写入正式页面规格或数据契约。

## 验证与出口

| 范围 | 必须观察的行为 | 出口要求 |
| --- | --- | --- |
| 入口与隔离 | 技术实验室可进入；退出后正式笔记不变；实验输入不保存 | 路由和数据边界可说明、可复现 |
| 中文真实输入 | 拼音预输入、选词、退格、连续输入、换行、表情与混合中英文 | 不打断预输入、不重建输入框、不丢文字；原生输入法人工操作记录范围 |
| 可见范围 | 光标在首行、中间、末行、空行，自动折行和手动换行 | 当前行定位正确，一行/两行切换不意外露出其他行 |
| 滚动与布局 | 输入框内部滚动、拖动、键盘升降、小窗与尺寸变化 | 遮罩跟随并正确裁切，光标离开视口或坐标失效时全遮；观察短暂闪露 |
| 选区与系统 UI | 长按、跨行选择、全选、选择手柄、放大镜和菜单 | 记录是否出现遮罩外暴露；未验证或存在泄露时不得宣称完成隐私保护 |
| 临时查看 | 按住、松手、滑出、触摸取消、多次快速操作 | 仅保持按压且页面活动时显示全文；结束后立即恢复 |
| 生命周期 | 收键盘、失焦、切后台、返回、重新进入 | 全遮并取消临时查看；过期回调不重新显露，主动恢复行为明确 |
| 主观体验 | 连续写一段后改字、回看，比较一行与两行 | 由用户评价是否安心、顺畅；构建与截图不替代用户认可 |

构建成功只证明工程可编译。截图和 UI 树只证明采样时刻，不能证明无瞬时闪露，也不能代替真实输入法、选区或系统缩略图验证。若首版有坐标滞后、遮罩闪露、放大镜泄露或输入不稳定，应保留实验状态并记录问题，再决定是否调整方案。

单台真机由协调者串行使用。本轮已知其他 Agent 在使用设备，安装、启动和输入前先确认当前界面与可用时机；一旦出现非本轮触发的导航、焦点或输入变化，停止发操作并退避一段时间，再观察状态后继续。不反复抢焦点、不强行回到实验页、不清空应用数据；无法获得独占窗口时完成构建，明确保留真机待验收项。
