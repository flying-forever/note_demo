# 隐私编辑 Demo 开发计划

创建及更新日期：2026-11-13。本文维护隐私编辑实验的当前候选设计与开发计划，不是正式笔记编辑器规格；实施状态与未验收项统一见[项目进度](../progress.md)，实验现状见[技术实验现状](../technical-demos.md)。首轮按行版本已提交为 `3c9e379`，过程保留在[首轮记录](../archive/2026-11-13-privacy-editor-demo.md)；后续见[椭圆记录](../archive/2026-11-13-privacy-editor-cursor-demo.md)与[矩形记录](../archive/2026-11-13-privacy-editor-rectangle-demo.md)。本轮改善连续输入刷新，纳入本轮提交，详细验证只维护在[本轮记录](../archive/2026-11-13-privacy-editor-input-refresh.md)。

## 目标与边界

验证公共场合写日记时，只显示光标附近少量文字是否既能减少屏幕内容暴露，又不妨碍持续输入、改字与短暂回看。用户已选择光标附近矩形与浅灰内容提示，本轮反馈连续输入反复出现“正在定位光标”和正文闪烁，调整普通输入刷新以保留上次有效局部窗口。仍不新增排版镜像或猜测字符宽度；用户已授权将矩形模式、浅灰内容提示和连续输入刷新修复纳入本轮提交；正式方案仍待后续体验决定。

入口为首页设置长按 → 技术实验室 → 隐私编辑。页面为 `pages/PrivacyEditorDemo.ets`，在 `diagnostics/DemoCatalog.ets` 和 `main_pages.json` 注册，沿用 `TECH_DEMOS_ENABLED` 开关。

实验仅使用内存中的纯文字样例与用户在实验页的临时输入，不读取正式笔记、不落盘，离开实验页不保存。无图片、标题独立编辑、分享、笔记锁定、加密、首页摘要遮挡或桌面卡片保护；不承诺输入法候选词、系统截图、后台任务缩略图、无障碍输出已获得保护。

## 设计依据

- [ZenJournal Discreet Mode](https://thezenjournal.com/posts/discreet)：隐藏历史日记而保留输入入口，说明公共场合继续写作与遮挡旧内容可以共存；其时间线方案不直接等同于长文光标附近遮挡。
- [iA Writer Focus Mode](https://ia.net/writer/support/editor/focus-mode?tab=focus-mode-mac)：跟随光标突出当前句或段，可借鉴活动区域选择；其余文字变灰仍可阅读，首版不将其当作隐私遮挡。
- [TextArea 共用控制器接口](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-universal-attributes-text-style/)：`getCaretOffset` 提供原生光标位置；同帧更新存在读取时序限制，必须验证排版与遮罩同步，不能以接口存在推断效果通过。

## 当前候选交互

| 场景 | 候选行为 |
| --- | --- |
| 进入实验页 | 默认启用隐私遮挡，尚未取得有效光标与排版信息时保持全遮 |
| 正常输入 | 默认光标周围模式，根据原生光标横坐标和当前视觉行位置露出局部矩形；按行模式保留用于比较 |
| 更多上下文 | 切换按行模式后，可比较当前视觉行与当前加上一行；视觉行指自动折行后的屏幕行，不是回车划分的整段 |
| 隐藏区域 | 不透明遮罩上绘制浅灰短条，仅提示内容存在，不绘制真实字形；按文本外接矩形和原生总行数示意正文块，空行和行尾不精确还原 |
| 普通输入与选区回调 | 不立即清除上次有效窗口，重复事件合并为一个空闲帧回调；获得有效坐标后重绘一次，窗口位置可短暂落后，不扩大可见区域 |
| 真实滚动、尺寸或模式变化 | 主动使坐标失效并先全遮，再等待有效排版；相同宽高/滚动偏移不触发重复失效；触摸跳转仍主动遮挡 |
| 坐标异常 | 关闭局部窗口；编辑中不再闪出“正在定位光标”提示，仅暂停时显示全遮提示 |
| 临时回看 | 按住查看全文，松手、触摸取消或手指滑出按钮即恢复遮挡，不提供无提示的持续全文显示 |
| 主动暂停 | 一键全遮；用户主动恢复后再取得有效位置，回到局部显示 |
| 收起键盘或结束编辑 | 保持隐私模式并全遮，不能因转为非编辑状态显示全文 |
| 页面隐藏、窗口失焦或应用退后台 | 取消全文查看并全遮；回到页面后需要主动恢复，过期回调不能重新打开可见带 |
| 跨行选择 | 不能因选区变大而扩大可见带；原生选择菜单、放大镜和系统复制的实际表现单独验收 |

遮罩保持原有正文排版空间，不强制打字机居中，不以模糊或低透明度真实文字作为隐藏手段，不增加随每次输入而播放的动画。占位短条不对应实际字数或逐字位置，因此不能用于精确定位某个隐藏词句。

| 候选参数 | 当前值与含义 |
| --- | --- |
| 光标周围窗口 | 目标宽度 192vp，左右为原生光标 x±96vp；上下对齐当前完整视觉行，名义高度 30vp；裁切至编辑视口 |
| 正文 | 字号 18、行高 30vp，固定缩放，四周内边距 16vp |
| 隐藏内容提示 | 资源 `privacy_placeholder`，浅灰 `#E1E5EB`；短条高度 7vp、横向步长 28vp |

上述参数仍为候选值。矩形上下对齐行高，目的是消除椭圆弧边造成的上下半截与邻行碎片；左右边界仍可能截断字形，视口上下缘也可能裁到部分行，因此不能保证所有字符完整。矩形是屏幕几何范围，不是光标前后固定 N 字；当前不新增 Text 排版镜像，不按估算字宽吸附边界。

## 实施步骤与职责

1. 核对当前正式规格和 API19 本地声明，固定隔离数据与实验路由。正式编辑器的保存、历史和数据库路径均不接入本实验。
2. 在独立页使用一个固定视口 `TextArea` 保存完整原文草稿；沿用原生中文预输入与光标能力，不把原文替换成星号，不截取另建可编辑草稿。
3. 建立独立的隐私显示状态，包含局部显示、按住全文查看、全遮，以及页面/窗口活动状态。用 Canvas 先绘制不透明遮罩和无字形短条，再按原生光标坐标挖出局部矩形或行带；Canvas 就绪前使用不透明兜底，字号、行高、间距集中定义，颜色引用资源。
4. 接入内容、光标、滚动和布局变化后的坐标刷新，处理像素/vp转换与当前视口裁切。普通输入保留上次有效窗口并合并到一个 `postFrameCallback` 空闲回调，坐标有效后只重绘一次；实际滚动、尺寸变化、模式切换与触摸跳转主动全遮，相同布局/偏移回调不重复失效。异常、暂停或失焦仍关闭窗口；异步结果带生命周期检查，页面离开时注销监听并使待处理回调失效。
5. 加入光标周围/按行模式、一行/两行切换、按住查看全文、全遮/恢复和样例体验入口，保证触摸取消与滑出恢复遮挡。
6. 命令行构建，随后按下表做可安排到的真机验证；根据实际结果更新[技术实验现状](../technical-demos.md)和[项目进度](../progress.md)。首轮反馈前不将候选规则写入正式页面规格或数据契约。

## 验证与出口

| 范围 | 必须观察的行为 | 出口要求 |
| --- | --- | --- |
| 入口与隔离 | 技术实验室可进入；退出后正式笔记不变；实验输入不保存 | 路由和数据边界可说明、可复现 |
| 中文真实输入 | 拼音预输入、选词、退格、连续输入、换行、表情与混合中英文 | 不打断预输入、不重建输入框、不丢文字；原生输入法人工操作记录范围 |
| 连续输入刷新 | 重复输入/选区回调、有效坐标更新与异常返回，连续软键盘输入并采样 | 普通输入不主动全遮或闪定位提示，重复回调合并；观察旧窗口短暂落后的体验，不能以离散截图声称逐帧无闪烁 |
| 可见范围 | 光标在首行、中间、末行、空行及左右边缘，自动折行和手动换行；切换局部矩形/一行/两行 | 矩形跟随光标，上下对齐当前视觉行；观察上下碎片是否改善，明确左右边界与视口边缘裁字风险，不误称固定字数范围 |
| 隐藏内容提示 | 有字/空白/空行/短行与长段，Canvas 首次就绪及尺寸变化 | 只见浅灰占位短条，不出现真实字形；接受占位仅示意块范围，检查首次绘制与重绘期间兜底 |
| 滚动与布局 | 输入框内部滚动、拖动、键盘升降、小窗与尺寸变化 | 遮罩跟随并正确裁切，光标离开视口或坐标失效时全遮；观察短暂闪露 |
| 选区与系统 UI | 长按、跨行选择、全选、选择手柄、放大镜和菜单 | 记录是否出现遮罩外暴露；未验证或存在泄露时不得宣称完成隐私保护 |
| 临时查看 | 按住、松手、滑出、触摸取消、多次快速操作 | 仅保持按压且页面活动时显示全文；结束后立即恢复 |
| 生命周期 | 收键盘、失焦、切后台、返回、重新进入 | 全遮并取消临时查看；过期回调不重新显露，主动恢复行为明确 |
| 主观体验 | 连续写一段后改字、回看，比较光标周围、一行与两行，以及浅灰占位 | 由用户评价是否安心、顺畅；构建与截图不替代用户认可 |

构建成功只证明工程可编译。截图和 UI 树只证明采样时刻，不能证明无瞬时闪露，也不能代替真实输入法、选区或系统缩略图验证。若首版有坐标滞后、遮罩闪露、放大镜泄露或输入不稳定，应保留实验状态并记录问题，再决定是否调整方案。

单台真机由协调者串行使用。本轮已知其他 Agent 在使用设备，安装、启动和输入前先确认当前界面与可用时机；一旦出现非本轮触发的导航、焦点或输入变化，停止发操作并退避一段时间，再观察状态后继续。不反复抢焦点、不强行回到实验页、不清空应用数据；无法获得独占窗口时完成构建，明确保留真机待验收项。
