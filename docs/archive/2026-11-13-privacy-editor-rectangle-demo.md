# 隐私编辑矩形窗口实现与验证

记录日期：2026-11-13。本文维护本轮矩形窗口的详细实现与验证，不作为正式规格。[首轮按行记录](2026-11-13-privacy-editor-demo.md)与[椭圆版本记录](2026-11-13-privacy-editor-cursor-demo.md)保持历史，当前状态见[项目进度](../progress.md)，候选设计见[开发计划](../plans/privacy-editor-demo-plan.md)。

## 目标与版本边界

用户希望把光标周围改为矩形，减少半截字，决定先用矩形做最小迭代，继续保留小范围显示和隐藏区域的浅灰内容提示。首轮按行版本既有提交仍为 `3c9e379`；之后的椭圆/浅灰占位及本轮矩形修改均保持未提交，本轮不新增提交。

## 当前方案

- 只改变 Canvas 局部露出形状，不改动单个原生 `TextArea` 的输入、预输入或完整原文草稿路径；不新增 Text 排版镜像，不以估算字宽吸附边界。
- 默认光标周围窗口目标宽度 192vp，左右取原生光标横坐标±96vp；上下恰好对齐当前完整视觉行，名义行高 30vp，最终裁切至编辑视口。靠近左右边缘时可见宽度可能小于目标值。
- 不采用圆角或椭圆弧边，以避免弧边跨越上下行字形；这只是几何形状改善，左右两条直边仍可能截断字符，视口上下缘也可能裁到部分行，不保证完整字形，更不等于前后固定 N 字。
- Canvas 不透明底、无真实字形的浅灰短条、当前行/当前加上一行对照、按住查看全文和失焦全遮继续保留。短条只示意内容存在，不精确还原空行、行尾或实际字数。
- 数据仍为隔离的页内内存样例和临时输入，不读写正式笔记，离页不保存。
