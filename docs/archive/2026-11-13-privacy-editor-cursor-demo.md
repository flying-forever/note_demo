# 隐私编辑光标周围模式实现与验证

记录日期：2026-11-13。本文是本轮新增模式的唯一详细实现与验证记录，不作为正式规格。[首轮按行记录](2026-11-13-privacy-editor-demo.md)保持历史；当前状态见[项目进度](../progress.md)，候选设计见[开发计划](../plans/privacy-editor-demo-plan.md)。

## 授权与版本范围

用户本轮要求先提交已完成的上版，再增加光标周围模式，并让隐藏区域略能看出有内容。上版已提交为 `3c9e379`，共 8 个文件，不含用户个人备忘 `用户的.md`。本轮新增模式尚未提交，未将上版提交授权扩大到新增修改。

## 当前实现

- 继续使用独立实验页 `pages/PrivacyEditorDemo.ets` 和单个固定视口 `TextArea`，完整原文仍只有页内一份草稿；临时样例与输入不读写正式笔记，离页不保存。
- 默认光标周围模式：通过原生 `getCaretOffset` 获取光标横坐标，以光标所在视觉行中心作为纵坐标，Canvas 挖出椭圆窗口。当前候选水平半径 96vp、垂直半径 22vp；不是按字符计算的前后 N 字。首次测试纵半径为 34vp，观察到邻行局部字形后收窄，不将首次截图当作最终参数效果。
- 保留按行显示及当前行/当前加上一行切换，方便对比不同可见范围。
- 隐藏部分先用不透明底覆盖，再绘制浅灰短条，只提示内容存在，不绘制或淡化真实字形。短条基于原生文本外接矩形与总行数，不精确恢复空行、行尾或字数。
- 占位色资源为 `privacy_placeholder`（`#E1E5EB`）；短条高度 7vp，横向步长 28vp。正文固定字号 18、行高 30vp、内边距 16vp。
- Canvas 就绪前使用不透明兜底；坐标改变时先全遮，排版与光标有效后重绘局部窗口。布局尺寸变化先将遮罩标记为未就绪，Canvas 实际宽高与新布局一致且重绘完成后才移除兜底；暂停时也排一帧重绘，避免尺寸变化后长期保留旧遮罩。按住查看全文、立即遮住、失焦/后台全遮和生命周期检查延续上版。

椭圆边缘可能截断字形，也可能露出上下相邻视觉行的局部内容，这是当前候选几何窗口的边界。尚未决定正式产品是否采用该形状与参数，不宣称完整字形或固定字数范围。

## 本轮重点待验证

1. 首次进入、Canvas 就绪前以及坐标刷新时保持不透明兜底；尺寸变化后遮罩正确重绘，不出现空白 Canvas 露出全文。
2. 光标在左右边缘、首末行、空行、自动折行处移动时，椭圆跟随且裁切明确；观察裁字和相邻行局部暴露是否影响体验。
3. 隐藏区域只显示浅灰占位，按行/光标周围切换不丢输入，不误把短条当成实际字形或字数。
4. 比较两种模式下的持续中文预输入、选词、删除、换行、复杂emoji、内部滚动与小窗尺寸变化。
5. 回归按住查看、松手/滑出/取消/多指、键盘收起、窗口失焦、后台恢复与离页重进；系统选区/放大镜、无障碍及瞬时闪露继续单列验证。

真机继续由协调者串行使用，出现非本轮触发的导航或输入则停止并退避。构建、截图和 UI 注入都不能替代完整真实输入法、焦点和宿主流程验收。
