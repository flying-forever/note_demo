# 设置菜单与首页视图验收

> 历史记录：2026-11-12 验收，仅代表所列设备、版本与场景；当前规格见[页面规格](../pages.md)，剩余项见[项目进度](../progress.md)。

2026-11-12。当前连接设备（1840×2800），覆盖安装本轮 debug HAP 后验收；构建与安装命令见[开发指南](../development.md)。

## 范围

- 设置短按菜单：两项内容、尺寸与定位、遮罩/返回关闭；长按仍进入技术实验室。
- 视图切换：瀑布/列表、当前名称更新、列表单列行、分组筛选、卡片打开与返回、列表滚动与标题收起、滚动后切换回顶。
- 持久化：Preferences `note_settings/view_mode`，两种视图分别强制停止后重启保留；快速连续切换后最终值保留。
- 更多：独立设置页标题与返回，返回首页保持分组和视图。

## 结果

- `assembleHap` 构建成功，覆盖安装并启动。
- 菜单打开后显示当前视图名和“更多”；菜单文字位置与宽200vp、距顶60vp、距右16vp的设计一致。点击遮罩、系统返回均关闭菜单且不退出应用。
- 瀑布视图：京都的清晨标题宽至870px，锦市场小吃清单位于 x970，保持两列。
- 列表视图：标题行宽至1540px，京都的清晨与夜行巴士到京都上下单列；选择“美食”后仅显示美食笔记；点击京都的清晨进入浏览，返回后仍为列表。
- 列表滚动上滑后大标题收起，“笔记”固定在顶栏 y123；滚动后切换视图，列表从首条开始。
- 列表视图下拉展开搜索行，首行由 y507 下移到 y647；随记中的长笔记在列表行正常显示标题与时间。
- 强制停止并重启：列表、瀑布分别恢复；连续三次切换（瀑布→列表→瀑布→列表）后重启仍为列表。
- 更多→设置页标题居中，返回后首页分组与视图保持不变。
- 长按设置图标进入“技术实验室”，未同时弹出视图菜单。
- 截图与UI树保存在工程忽略的 note_by_agent/build/verification/acc-*。

## 边界

- 空分组/空列表样式、其他设备、系统字体缩放和视觉主观参数未验收。
- 独立设置页本轮只有标题与返回，具体设置项未定义。
- 验收结束后视图恢复为瀑布。
