# 状态栏与导航栏沉浸真机验收

> 历史记录：2026-11-13 验收，仅代表所列设备、版本与场景；当前规格见[页面规格](../pages.md)，剩余项见[项目进度](../progress.md)。

2026-11-13。当前连接设备 DMG-W00，HarmonyOS 6.1.0.139(C00E125R2P3)，屏幕 1840×2800，密度 2.5。覆盖安装本轮 debug HAP 后启动验收；构建与安装命令见[开发指南](../development.md)。

## 范围

- 主窗口全屏、状态栏/导航栏透明，页面背景延伸到上下系统栏区域。
- 首页、设置页、桌面预览、主编辑页和技术实验室/实验页的上下让位与交互控件避让。
- 浅色页面、深色动态皮肤、图片详情黑底的系统栏图标明暗切换及退出恢复。
- 浮动输入法弹出、横竖屏切换后的避让区刷新。
- 底部手势指示条的可见性观察；三键导航、折叠和其他设备不在本轮可用范围。

## 结果

- `assembleHap` 构建成功，覆盖安装并启动，无崩溃；最终未提交诊断日志代码。
- 启动时避让区为 top=97px、bottom=70px，密度 2.5，即约 38.8vp/28vp；页面按该值上下让位。窗口管理信息显示主窗口覆盖 0,0–1840,2800。
- 首页：状态栏区域颜色为 `#F2F2F2`，与页面背景一致；顶部栏从 y98 开始，设置图标 105–215；悬浮按钮 2510–2640，底部留出避让区和间距。截图抽检状态栏时钟区域存在深色像素，验证浅底深色图标。
- 设置菜单：容器 y247–557，位于状态栏下方；短按打开“列表/更多”，点击“更多”进入设置页。
- 设置页：顶栏 98–237，返回按钮 112–222；页面背景延伸到屏幕底部，未进入状态栏。
- 主编辑页：顶栏 y137（97px 避让 + 16vp 内边距）；皮肤面板 y2325–2730，底边比屏幕底部高 70px；浅色皮肤状态栏为浅底深色图标。
- 深色动态皮肤（星夜萤火）：状态栏区域像素约 `#0B1423`，与皮肤深色背景一致；时钟区域亮色像素明显增加，验证深底白色图标。
- 图片详情：背景和状态栏区域均为 `#000000`，图标切换为白色；关闭详情后恢复星夜萤火深底白图标，再返回首页恢复浅底深色图标。
- 桌面预览：顶栏 157–257，内容区底部空白止于 2670；浅色背景和深色系统栏图标一致。
- 技术实验室及长文、数据库、原生编辑器三个实验页：页面顶部空白/顶栏位于 y137 之后，列表或内容底边约 2690；四页均显式绘制白色背景，状态栏区域为白色，图标为深色。
- 键盘：标题输入框位于 y327；系统浮动键盘窗口覆盖约 x694–1619、y515–1313。键盘弹出后顶部栏仍在 y137，状态栏未被遮挡；本次未验证全宽键盘和其他输入法。
- 旋转：用 DisplayManagerService 调试命令切到 2800×1840，避让区仍为 top=97px、bottom=70px，顶栏仍在 y137，页面按新宽度重排；恢复到 1840×2800、rotation=270 后布局恢复。旋转使用系统调试命令，不是物理翻转。
- 底部手势指示条在 y2772–2784 可见；浅色页面为低对比深灰线，深色皮肤为低对比浅灰线。该指示条由系统绘制，`navigationBarContentColor` 未表现出控制能力，本轮不宣称已适配其颜色。
- 截图和 UI 树保存在工程忽略的 `note_by_agent/build/verification/`，不作为提交内容。

## 边界

- 本轮设备为手势导航；三键导航未切换验证。
- 设备为平板，未做折叠/展开和真实物理旋转；其他尺寸、其他品牌/系统版本未验。
- 输入法为系统浮动键盘；全宽键盘、实体键盘和其他输入法未验。
- 全屏或避让区读取失败的回退路径未做故障注入，仍只有静态核对。
- 手势指示条颜色由系统管理，属于系统行为，不是本应用可保证的视觉参数。
- 视觉主观参数和不同系统字体缩放未做用户验收。
