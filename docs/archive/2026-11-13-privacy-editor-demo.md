# 隐私编辑 Demo 首轮实现与验证

记录日期：2026-11-13。本页维护本轮详细验证事实，不作为正式产品规格。当前结论见[技术实验现状](../technical-demos.md)，尚未验收项统一见[项目进度](../progress.md)，候选设计和出口见[开发计划](../plans/privacy-editor-demo-plan.md)。

## 实现与环境

- 新增独立 `pages/PrivacyEditorDemo.ets`，通过 `DemoCatalog` 和 `main_pages.json` 注册到技术实验室；入口为首页设置长按 → 技术实验室 → 隐私编辑。
- 纯文字样例和临时输入仅保留在页内内存，不读写正式笔记，不接保存、图片、分享或数据库。
- 完整草稿由一个固定视口 `TextArea` 持有，通过 `getCaretOffset`、`getTextContentRect` 和固定行高定位当前视觉行，上下不透明遮罩覆盖其余内容；可切换当前行/当前加上一行。
- 默认全遮，点击继续编辑后请求焦点；支持立即遮住、按住查看全文。收起键盘、页面隐藏或窗口失焦取消临时查看并全遮，异步刷新结果检查页面生命周期。
- 窗口事件绑定后通过 `isFocused()` 查询当前实际焦点，避免异步绑定前已失焦时误认窗口活动；窗口销毁事件也进入全遮。相关最终代码已构建并安装，最终版本 UI 回归仍待确认。
- 目标及兼容 SDK 为 HarmonyOS 5.1.1(API19)，使用[开发指南](../development.md)的本机 DevEco JBR、SDK 和命令行构建。

## 当前体验局限与待验收

- 当前系统浮动键盘会遮住部分可见行，影响局部编辑的可读性；尚未形成键盘避让的体验通过结论。
- 持续输入/删除/换行、复杂 emoji 与混合文本、长文滚动、小窗和布局尺寸变化未完成。
- 按住查看后的滑出、触摸取消、多指干扰及快速反复操作尚未完成；目前只验证按住/松手采样。
- 跨行选择、全选、选择手柄、放大镜未完成。代码关闭原生选择菜单不能证明所有系统浮层均被遮住。
- Home/`aa start` 返回与离页重进已有局部验证，不扩大为所有窗口失焦、系统弹窗或小窗切换；最终代码构建和安装已成功，受设备共享干扰的最终版本 UI 回归待确认。
- 瞬时闪露、无障碍输出、系统截图、后台任务缩略图和输入法候选词不在已确认保护范围；本实验不提供加密或笔记锁定。
- 用户尚未评价一行/两行的实际写作舒适度，不能以构建或截图代替效果认可。

最终回归前探测到设备已离开实验页，可能存在其他 Agent 操作。该批处理未及时在探测后停止，继续执行了最终安装和启动；协调者确认后停止设备操作并退避。退避 30 秒后只读观察设备停留技术实验室，核对界面并点击打开实验，下一步 guard 再次发现已回到首页，遂停止最终 UI 操作，不再争抢。

界面变化原因未确认，可能涉及并发导航或重装等，不归因于某个 Agent，也不将受干扰阶段计为 UI 验证通过。`hilog -d` 过滤未见 `PrivacyEditorDemo`、`TypeError` 等错误，但不能据此排除运行问题。最终交付状态为：最终构建与安装成功，前轮功能版的局部真机证据保留；最后窗口焦点查询、占位文本居中及窗口销毁事件改动后的 UI 回归未完成。
