# 设计规范

当前代码基线（2026-11-12），不等于用户已最终验收全部视觉参数。参考截图在picture/，交互见[页面规格](pages.md)。尺寸通常为vp，fontSize为ArkUI字号数值，随系统字体缩放，不作为物理像素。

## 颜色

资源color.json定义：主题#FF6900、页面#F2F2F2、卡片#FFFFFF、主文字#1A1A1A、次文字#999999、弱文字#B3B3B3、分割线#E5E5E5。首页分组选中使用主题色和Medium字重，无胶囊或下划线。卡片无阴影，悬浮按钮阴影radius10、#33000000、offsetY4。

笔记正文及首页卡片以model/NoteSkin.ets配色为准；默认白皮肤secondary为#777777，与全局次文字色不同。当前12款皮肤（4静态、8动态），ID和颜色集中在该文件，未知ID默认白。深色皮肤使用浅色文字及图标colorFilter；卡片仅使用静态配色。

系统栏背景透明，图标颜色按页面/皮肤背景亮度选择：首页、设置、桌面预览、技术实验等浅色背景使用深色图标；星夜萤火、极光漫游、星轨漫游、深蓝等深色皮肤及图片详情黑底使用白色图标。图片详情关闭后恢复当前皮肤图标。手势指示条颜色由系统管理，不能把 navigationBarContentColor 当作已控制该项。

## 间距与裁切

首页左右16、卡内14、卡间/列间12、卡圆角12、最小高150；顶部栏46、大标题槽56、分组44、搜索行0～56、搜索框40圆角20。列表视口12圆角clip，列表底留96；悬浮按钮52，右20底36。设置点击容器44；设置菜单宽200、行高56、圆角20、距顶60右16，遮罩#33000000。列表视图为单列整宽行，行内边距14、最小高96，标题与时间同行、摘要最多2行。

编辑页padding16，导航点击44、间距8、图标24；正文视口圆角12并裁切，图片圆角8，正文末尾空白12。文字输入自身padding0、正文输入圆角0，保证浏览/编辑文字起点对齐。更多菜单宽200、行高56、圆角20；文件夹展开40。皮肤面板高162，显式底部定位，不遮顶部操作。图片描述使用限宽圆角面板和当前皮肤配色。

半模态padding8、外框圆角20、输入边界14、按钮高32、正文最小高120；单文字块填剩余高度，多块滚动。宿主自身标题/预览和完成按钮占用空间不在应用布局控制范围。

系统栏高度运行时读取，不写死。页面上下内边距为原内边距加对应避让高度；首页设置菜单顶部和悬浮按钮底部同步加安全区，编辑页更多/文件夹浮层顶部加安全区，皮肤面板底部抬升安全区，图片详情四边加安全区。

## 动态与验收

背景覆盖编辑页且不拦触摸；effect分发，隐藏/编辑/图片覆盖暂停、离页清理。树叶renderGroup(true)保留叶脉，宽高/透明度后animation(null)，再限定旋转循环，窗口变化不加入循环。樱花落地停留后淡出；其他效果参数以components内实现为准，不能把初版三款说明当完整目录。
