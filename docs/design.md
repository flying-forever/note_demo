## 组件风格

- 顶部导航：自绘单行，笔记/待办 + 居中当前 tab 小标题 + 右侧设置图标，固定不滚动。
- 大标题槽：位于导航下方，默认显示当前 tab 大标题；上滑随滚动偏移收起，为列表让出空间。
- 分组：横向滚动文字标签（横向 List），「全部」在最前，最右侧固定文件夹图标；位于大标题槽下方，随其一起上移。
- 列表：双列瀑布流（Scroll + 两个 Column），卡片式。
- 列表铺满导航下方，顶部用恒定 padding（大标题槽 + 分组栏）占位；大标题/分组栏以覆盖层绘制，避免头部收起时列表双倍速滚动。
- 列宽/间距：列间距 12vp，卡片宽度随列宽（不要依赖 FlowItem 内百分比宽度）。
- 搜索：仅在列表到顶继续下拉超过阈值（30vp）时展开，独占大标题下方一行；上滑优先收起。采用「阈值触发 + 整段动画」，不做跟手渐变。
- 底部导航：不做。

## 搜索栏展开/收起方案

2026-11-06 调整为独立搜索行，替代此前共享大标题槽的方案。

- 排列：固定导航、大标题行（56vp）、搜索行（展开高 56vp，搜索框 40vp）、分组栏。
- 默认仅大标题展开；到顶后主动下拉约 30vp，以 180ms 动画展开搜索行，大标题保留。
- 上滑先以 180ms 动画收搜索，动画期间拦截列表滚动；完成后继续上滑才收大标题并渐显小标题。
- 搜索行高度与列表顶部占位同步动画；列表占位不随大标题收起而缩短，避免双倍速滚动。
- 仅触摸滚动累计下拉距离，松手清零；惯性及回弹不触发展开。
- 搜索常驻挂载，收起后不接收点击。
