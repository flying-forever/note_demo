## 组件风格

- 顶部导航：自绘单行，笔记/待办 + 居中当前 tab 小标题 + 右侧设置图标，固定不滚动。
- 大标题槽：位于导航下方，默认显示当前 tab 大标题；上滑随滚动偏移收起，为列表让出空间。
- 分组：横向滚动文字标签（横向 List），「全部」在最前，最右侧固定文件夹图标；位于大标题槽下方，随其一起上移。
- 列表：双列瀑布流（Scroll + 两个 Column），卡片式。
- 列表铺满导航下方，顶部用恒定 padding（大标题槽 + 分组栏）占位；大标题/分组栏以覆盖层绘制，避免头部收起时列表双倍速滚动。
- 列宽/间距：列间距 12vp，卡片宽度随列宽（不要依赖 FlowItem 内百分比宽度）。
- 搜索：仅在列表到顶继续下拉超过阈值（30vp）时展开，与大标题共用同一槽位、互斥；上滑收起。采用「阈值触发 + 整段动画」，不做跟手渐变。
- 底部导航：不做。

## 搜索栏展开/收起方案

方案：阈值触发 + 整段动画。

- 下拉阶段不跟手：`searchProgress` 保持 0，不显示半透明搜索栏。
- 累计下拉量 ≥ 30vp 才触发，用 `animateTo`（约 180ms）整段展开到 1，大标题同步淡出。
- 未过阈值松手不改变状态，避免「标题 → 半显搜索 → 标题」闪回。
- 收起判定看真实内容偏移 `offset > 8`，而不是 `deltaY` 方向。
- 搜索栏常驻挂载、只控 `opacity`；未展开时 `HitTestMode.None`，避免在 0 附近反复挂载/卸载造成闪烁。

理由：

- 跟手渐变的半透明态与同槽大标题叠加，未过阈值松手回弹必然闪一下，无法根除。
- `edgeEffect(Spring)` 回弹会产生正向 `deltaY`，若用 `deltaY > 0` 判上滑会误关搜索；回弹时 `offset` 仍 ≤ 0，用内容偏移判定可靠。
- 不拆成「标题一行 + 搜索一行」：两者都高 56vp 且互斥，共享槽位切换时头部高度不变、列表不跳动；拆两行会让搜索展开时头部变高、内容整体下移，且削弱「上滑收起大标题」的效果。
