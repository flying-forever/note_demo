## 首页（home）

> 状态：占位实现中。布局来自用户口头描述，细节待看效果后调整。

### 布局
```
Stack（右下角悬浮新建按钮）
└── Column
    ├── 顶部导航（固定，始终可见）
    │   ├── 居中：笔记 / 待办小切换项（上滑后渐显）
    │   └── 右侧：设置图标
    └── Stack（笔记 tab，占满剩余高度）
        ├── Scroll（铺满导航下方）
        │   ├── 顶部占位 padding = 大切换行 56 + 分组栏 44 + 搜索行当前高度
        │   └── 双列笔记卡片（20 条假数据，短分组也从顶部排起）
        └── 覆盖层（顶部，背景同页面）
            ├── 大切换行（56vp，靠左，可收起）
            ├── 搜索行（0～56vp，内含 40vp 搜索框）
            └── 分组横向列表（44vp，上滑时随大标题槽一起上移）
                ├── 全部 / 旅途 / 美食 / 攻略 / 随记（横向滚动）
                └── 最右侧文件夹图标（固定，跳转分组管理）

待办 tab 使用顶部导航、大切换行和占位内容。
```

### 元素
- 页面背景：淡灰；卡片：偏白。
- 卡片字段：标题、摘要（最多 4 行）、时间；无缩略图。
- 卡片高度：约屏幕 1/5；两列瀑布流，单列切换后续再做。
- 页边距偏宽；卡片一行约 9 个字（字号以此反推）。
- 新建：右下角悬浮按钮。
- 大切换项靠左，选中 44vp Bold，未选中 34vp Regular。
- 小切换项居中，选中 22vp Bold，未选中 17vp Regular。两组均可切换「笔记 / 待办」。

### 交互
- 点击「笔记 / 待办」：切换 tab，默认笔记；切换时收起搜索、复位大标题。
- 点击分组项：筛选该组笔记。
- 点击文件夹图标：跳转分组管理页（当前 toast 占位）。
- 点击笔记卡片：跳转编辑页（当前 toast 占位）。
- 点击新建：新建笔记并跳转编辑页（当前 toast 占位）。
- 点击设置：设置页（当前 toast 占位）。
- 下拉先回到列表顶部并恢复大切换项。手指继续下拉才展开搜索行。快速下甩回顶停在大切换项。
- 上滑先跟手收起搜索行，剩余距离继续滚动列表。列表上滑前 56vp 收起大切换项，小切换项同步渐显。
- 慢拖松手后按搜索行显露比例归位。至少显露一半时展开，否则收起。上滑惯性继续消耗搜索行剩余高度，收完后交给列表。弹性回正不改变搜索行高度。搜索输入暂未接入查询。
