### 布局
```
Stack（右下角悬浮新建按钮）
└── Column
    ├── 顶部导航（固定，始终可见）
    │   ├── 左侧：笔记 / 待办（可切换，默认笔记）
    │   ├── 居中：当前 tab 小标题（上滑后渐显）
    │   └── 右侧：设置图标
    └── Stack（笔记 tab，占满剩余高度）
        ├── Scroll（铺满导航下方）
        │   ├── 顶部恒定占位 padding = 大标题槽 56 + 分组栏 44
        │   └── 双列瀑布流笔记卡片（约 20 条假数据）
        └── 覆盖层（顶部，背景同页面）
            ├── 大标题槽（56vp，可收起）
            │   ├── 默认：当前 tab 大标题（左对齐，44vp Bold）
            │   └── 搜索态：搜索栏（与大标题共用同一区域，互斥）
            └── 分组横向列表（44vp，上滑时随大标题槽一起上移）
                ├── 全部 / 旅途 / 美食 / 攻略 / 随记（横向滚动）
                └── 最右侧文件夹图标（固定，跳转分组管理）

待办 tab：顶部导航 + 大标题槽（显示「待办」）+ 占位内容。
```

### 元素
- 页面背景：淡灰；卡片：偏白。
- 卡片字段：标题、摘要（最多 4 行）、时间；无缩略图。
- 卡片高度：约屏幕 1/5；两列瀑布流，单列切换后续再做。
- 页边距偏宽；卡片一行约 9 个字（字号以此反推）。
- 新建：右下角悬浮按钮。
- 大标题：当前 tab 名，44vp Bold，左对齐，距设置行下方一行。
- 上滑小标题：当前 tab 名，17vp Medium，居中，随大标题收起渐显。

### 交互
- 点击「笔记 / 待办」：切换 tab，默认笔记；切换时收起搜索、复位大标题。
- 点击分组项：筛选该组笔记。
- 点击文件夹图标：跳转分组管理页（当前 toast 占位）。
- 点击笔记卡片：跳转编辑页（当前 toast 占位）。
- 点击新建：新建笔记并跳转编辑页（当前 toast 占位）。
- 点击设置：设置页（当前 toast 占位）。
- 搜索栏：仅在列表已到顶部且继续下拉超过阈值（约 30vp）时展开；列表中部下拉不触发。阈值触发后整段动画展开，不做跟手半显。
- 搜索栏隐藏：上滑列表即收起（不设阈值），不再使用「取消」按钮。
- 大标题收起：列表上滑前 56vp 内渐进收起，小标题同步渐显；回到顶部恢复。
- 大标题与搜索栏共用同一 56vp 槽位：展开搜索时大标题淡出，收起搜索后按滚动偏移决定大标题/小标题。

### 首页顶部交互调整（2026-11-06，已实施，待视觉验证）

本节替代上文搜索与大标题共用槽位的旧交互说明。搜索行高 56vp，内含 40vp 搜索框。

- 固定顶部导航保持原有 tab 和设置入口；居中小标题只由大标题收起程度决定。
- 从上到下依次为：固定顶部导航、大标题独立行、搜索独立行、分组栏、笔记列表。
- 三个稳定状态：紧凑态（小标题 + 分组栏）、标准态（大标题 + 分组栏，默认）、搜索展开态（大标题 + 搜索栏 + 分组栏）。
- 下拉顺序：列表先回到顶部并展开大标题；到顶后继续主动下拉约 30vp，整段动画展开搜索行。普通回顶和惯性回弹不触发搜索。
- 上滑顺序：先收起搜索行，期间大标题保持完整、小标题隐藏；搜索行完全收起后，再按上滑距离收起大标题并渐显小标题；其后正常滚动列表。
- 搜索行保留阈值触发与整段动画，避免回到跟手半显后松手闪回的旧问题；大标题保持原有连续收起效果。
- 搜索展开/收起造成的布局变化不作为用户滚动输入；布局、惯性回弹不能触发下一阶段。快速滑动也必须按阶段顺序处理。
- 切换 tab 收起搜索并恢复标准态；搜索输入、键盘与过滤行为另行确定，本提案只调整顶部展开交互。
- 验收重点：搜索展开时大标题仍可见；连续上滑小标题仅从隐藏变为显示一次；回顶不误开搜索；松手回弹不误关搜索；分组栏与首张卡片无重叠、空隙或跳动。
